# Найди меня — Telegram Mini App на Nuxt 4

Первый этап квеста реализован как Nuxt 4 / Vue-приложение. Интерфейс находится в `app/pages/index.vue`, изображение подсказки — в `public/assets/`, а Telegram webhook — в `server/routes/telegram-webhook.post.ts`.

## Запуск

1. Установите пакеты и запустите режим разработки:

   ```powershell
   npm install
   npm run dev
   ```

2. Для production соберите проект: `npm run build`. Запуск сборки: `npm start`.
3. На хостинге задайте переменные окружения, **не добавляя токен в исходники**:

   ```text
   NUXT_BOT_TOKEN=новый_токен_бота
   NUXT_WEB_APP_URL=https://your-domain.example
   ```

4. Установите вебхук (подставьте свой домен):

   ```text
   https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://your-domain.example/telegram-webhook
   ```

5. Напишите боту `/start`: он пришлёт кнопку «Открыть квест ✦».

> Токен, отправленный в переписке, нужно немедленно отозвать и выпустить новый через BotFather. Считайте его скомпрометированным.

Пока инструкция после поезда открывается в самом Mini App по кнопке «Я доехала». E-mail‑сценарий оставлен в коде как заготовка и будет подключён, когда появятся финальные время прибытия, адрес отеля и e-mail получателя.

Прогресс демо‑этапа сейчас хранится в браузере пользователя (`localStorage`). Для общего, защищённого прогресса между устройствами следующим шагом подключите базу данных и валидацию Telegram `initData` на сервере.
